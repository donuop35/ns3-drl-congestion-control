# 簡報 Pre-Flight Checklist

## 設備確認
- [ ] 投影機 / 螢幕分享正常
- [ ] 簡報檔案已準備（PPT / PDF / Markdown）
- [ ] GitHub repo 頁面已開啟
- [ ] Terminal 已準備（可選：跑 figure regeneration）

## 內容確認
- [ ] Talk Track 已練習至少一次
- [ ] 計時器設定 10 分鐘
- [ ] 每頁講 40–60 秒
- [ ] S1/S2 結果數字已背熟
- [ ] 限制說明已準備（Delay Proxy, Option B, S2 高丟包）

## 禁語確認
- [ ] 不會說「DQN beats TCP」
- [ ] 不會說「production-ready」
- [ ] 不會說「true RTT」
- [ ] 不會說「kernel-level TCP control」
- [ ] 不會過度解讀 S1 degenerate policy

## Fallback 確認
- [ ] 若 live command 失敗，可直接展示既有 figures
- [ ] 若被問到 PPO，回答「Phase 6 已由 Spec Owner 決定跳過，列為 future work」
- [ ] 若被問到 real deployment，回答「本專題為 MVP prototype，運行於模擬環境」
