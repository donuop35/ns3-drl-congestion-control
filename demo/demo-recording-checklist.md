# Demo 錄影 Checklist

## 錄影前
- [ ] 確認螢幕解析度適合錄影（建議 1920×1080）
- [ ] 關閉不相關的應用程式與通知
- [ ] 開啟 GitHub repo 頁面
- [ ] 開啟 Terminal（PowerShell 或 WSL2）
- [ ] 確認 `python scripts/phase5/generate_final_figures.py` 可正常執行
- [ ] 確認 `openspec validate reporting-figures-and-demo --strict` 回傳 valid
- [ ] 準備好 `final-demo-runbook.md` 作為參考
- [ ] 設定計時器（10 分鐘）

## 錄影中
- [ ] 開場自我介紹與專題名稱
- [ ] 依照 Runbook 順序展演
- [ ] 每個步驟停頓 2–3 秒讓觀眾看清
- [ ] 口頭解釋所有展示的數據與圖表
- [ ] 不要跳過限制說明
- [ ] 不要說禁語（DQN beats TCP, true RTT, kernel-level, production-ready）

## 錄影後
- [ ] 確認影片長度不超過 10 分鐘
- [ ] 確認音質清晰
- [ ] 確認字幕/畫面可讀
- [ ] 上傳或提交
